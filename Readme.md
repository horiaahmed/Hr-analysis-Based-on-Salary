#  Salary Analysis Dashboard

### 📊 Project Overview  
The **Salary Analysis Dashboard** is an end-to-end Excel data analytics project designed to explore, analyze, and visualize salary trends across multiple factors such as **job title, experience, education, department, and location**.  

This project demonstrates the **complete data analytics workflow** — from **data cleaning and transformation** using Power Query, to **analysis using Pivot Tables**, and finally, to **insightful dashboard visualization** and **recommendations**.

---

###  Tools & Technologies  
- **Microsoft Excel**
  - Pivot Tables  
  - Slicers & Filters  with reset filters button
  - Conditional Formatting  
  - Interactive Charts  
  - KPI Cards  
  - Nav bar to easily move between worksheets
- **Power Query**
  - Data Cleaning & Transformation  
  - Removing Duplicates & Null Values  
  - Standardizing Column Names  
  - Merging & Structuring Data  

---

### Step 1: Data Cleaning (Power Query)
Before analysis, the dataset was cleaned and prepared using **Power Query**:
- Removed duplicate and missing records.  
- Corrected inconsistent job titles and department names.  
- Standardized salary and experience formats.  
- Created a structured data model suitable for Pivot Table analysis.  

---

### Step 2: Data Analysis (Pivot Tables)
Used **Pivot Tables** to uncover key insights:
- Total Salary , Employee Numbers , Total Locatons , Total Departments 
- Salary distribution across departments and job titles.  
- Relationship between **experience** and **salary growth**.  
- Comparison of average salaries based on **education level**.  
- Salary variations across **different locations**. 
- Top jobs Salary  

Each Pivot Table was dynamically linked to filters, allowing for interactive data exploration.

![](https://github.com/horiaahmed/Hr-analysis-Based-on-Salary/blob/main/2025-10-05%20(3).png)
---

### Step 3: Dashboard Design
Designed an **interactive and professional Excel dashboard** combining charts, KPIs, and slicers to provide a clear overview of the data:
- **Key Metrics:** Total Salary (4.96M), Total Employees (500), Departments (7), Locations (7).  
- **Visuals Included:**
  - Top Jobs by Salary  
  - Salary by Experience Year  
  - Salary by Educational Level  
  - Salary by Department  
  - Average Salaries by Location  

The dashboard uses a consistent **brown and white color theme**, enhancing readability and visual harmony.
